# Donor Blog Comment Prospecting Agent

n8n-агент для автоматического поиска донорских блогов, пригодных для размещения ссылок через комментарии — с определением CMS и фильтрацией по техническим критериям.

## Что делает
1. По списку ниш и поисковых шаблонов ("powered by wordpress" + "leave a comment" и т.п.) формирует комбинации запросов и ищет кандидатов через Google Search API (Serper).
2. Убирает дубли по домену.
3. Для каждого кандидата загружает HTML и определяет CMS (WordPress, Ghost, Blogger, Joomla, Drupal, Bitrix, TYPO3, MODX, Tilda) по сигнатурам в разметке.
4. Отсеивает форумы (по характерным признакам — phpBB, vBulletin, XenForo и т.д.), оставляя только блоги.
5. Проверяет наличие формы комментариев и требование регистрации для комментирования.
6. Записывает результат в Google Sheets со статусом `ready_to_contact` (блог + форма комментариев без регистрации) или `needs_review`.
7. Между проверками — пауза (антибан), чтобы не создавать подозрительную нагрузку на целевые сайты.

## Стек
n8n · Serper (Google Search) API · Google Sheets API · регулярные выражения и эвристики для CMS-детекции

## Зачем это нужно бизнесу
Автоматизирует первый, самый трудоёмкий этап линкбилдинга — поиск и первичную квалификацию донорских площадок, — снимая с линкбилдера ручной перебор десятков сайтов вручную.

## Настройка
Требуется API-ключ Serper и Custom Search Engine ID — хранятся в credentials/переменных окружения n8n, не в самом workflow-файле. Также нужен доступ к целевой Google-таблице через Google Sheets OAuth2.
